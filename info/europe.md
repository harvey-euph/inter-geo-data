# 英國在地語言與街頭文字習慣
- priority: 20
- id: uk-language
- targets: GB
- icon: 🇬🇧
- accent: #1d4ed8
- tags: Language, Geoguessr

- **【官方語言】**：英式英語 (British English)，威爾斯地區法律規定英威雙語並列。
- **【核心交通標牌系統（與美國的巨大差異）】**：
  - **GIVE WAY**：全英統一讓路倒三角形標誌（美國寫 YIELD！）。
  - **WAY OUT**：地鐵站、停車場與公共通道出口標誌（非 Exit）。
  - **NO ENTRY**：禁止進入（紅底白橫槓）。
  - **WAITING LIMITED** / **PAY AT MACHINE**：市區路邊停車限制告示牌。
  - **ZEBRA CROSSING**（斑馬線，兩側立有黃色閃爍貝里沙燈球 Belisha Beacon）/ *Pelican Crossing*。
  - **PUBLIC FOOTPATH**：鄉間特有的公眾健行步道木製或金屬箭頭指標。
- **【街頭超高頻英式生活招牌】**：
  - **Off-licence**：英國特有的外帶酒類零售小店（非酒吧 Pub）。
  - **Takeaway / Chippy**：外帶炸魚薯條店與快餐外賣招牌。
  - **Chemist / Pharmacy**：英國普遍稱藥局為 Chemist（如連鎖龍頭 *Boots*）。
  - **Car Park**：停車場統稱（美國稱 Parking Lot）。
  - **Post Office**：皇家郵政鮮紅色招牌與經典紅色圓筒郵筒 (Pillar Box)。
- **【門牌地址與郵遞區號】**：
  - 皇家郵政編碼格式獨特（如 *SW1A 1AA*, *EC1V 4PW*），常直接標在路名牌角落。
- **【威爾斯雙語區 (Wales)】**：
  - 路牌上方或下方必定帶有威爾斯語 (Cymraeg)：*ARAF / SLOW*（慢行）、*ALLAN / WAY OUT*、*YSGOL / SCHOOL*。


# 愛爾蘭在地語言與街頭文字習慣
- priority: 20
- id: ireland-language
- targets: IE
- icon: 🇮🇪
- accent: #16a34a
- tags: Language, Geoguessr

- **【雙官方語言憲法規範】**：愛爾蘭語（蓋爾語 Gaeilge）與英語。
- **【世界最著名的雙語路牌景觀】**：
  - **斜體綠字愛爾蘭語 + 正體黑字英語**：愛爾蘭所有地名與官方路牌，**上方一律為綠色斜體蓋爾語，下方為標準英文字母**（如 *Corcaigh / CORK*, *Áth Cliath / DUBLIN*）。看到綠色斜體地名 100% 鎖定愛爾蘭！
  - **GÉILL SLÍ / YIELD**：讓路標誌雙語並列。
  - **SOS / STOP**：停止標誌多為標準八角形 STOP。
- **【與英國的關鍵辨識差異】**：
  - **公制限速**：愛爾蘭限速標牌為白底紅圈的**公里 (km/h)**（如 *50 km/h, 100 km/h*），而英國限速牌**沒有單位且一律為英哩 MPH**！
  - 黃色虛線路肩邊線：愛爾蘭主要公路路緣常有黃色虛線，英國為白線。
- **【在地招牌與生活】**：
  - *An Post*（愛爾蘭國家郵政綠色招牌與綠色郵筒，英國為紅色！）、*Garda*（愛爾蘭國家警察局）、*Pub / Traditional Music*。


# 法國在地語言與街頭文字習慣

- id: france-language
- targets: FR
- icon: 🇫🇷
- accent: #2563eb
- tags: Language, Geoguessr

- **【官方語言】**：法語 (Français)
- **【核心交通標牌系統】**：
  - **STOP**：八角停止標誌寫英文「STOP」（非法文 Arrêt！）。
  - **CÉDEZ LE PASSAGE**：倒三角讓路標誌。
  - **RAPPEL**：最高頻路牌！出現在限速標牌下方，意為「再次提醒維持此限速」。
  - **SENS UNIQUE**（單行道）、**VOIE SANS ISSUE**（死胡同無尾巷）、**RALENTIR**（減速）、**DÉVIATION**（改道）。
  - **PRIORITÉ À DROITE**：法國最著名的「右方車輛優先權」交規。
- **【法國街頭經典招牌】**：
  - **BOULANGERIE / PÂTISSERIE**：法式長棍與糕點烘焙坊，小鎮靈魂中心。
  - **PHARMACIE**：綠色發光霓虹十字架標誌，標配時間與氣溫跳動顯示。
  - **TABAC**：國家特許菸草專賣店，建築外牆必掛有紅色雙菱形立體燈箱 (Carotte)。
  - **MAIRIE**：每座城鎮村莊中心的市政廳公署，門口懸掛法國與歐盟旗幟。
  - *Salle des Fêtes*（市民活動中心）、*Coiffure*（美髮沙龍）、*Boucherie / Charcuterie*（肉品熟食舖）。
- **【街道命名格式】**：
  - 藍底白字綠邊琺瑯街道牌：*Rue* (街), *Avenue (Av.)*, *Boulevard (Bd.)*, *Place (Pl.)*, *Allée*, *Impasse* (死巷), *Chemin* (小徑)。

  - **Parkieren**：瑞士德語停車動詞（德國稱 Parken）。
  - **PostAuto / CarPostal**：亮黃色車身、喇叭鳴響三音調的瑞士國家郵政巴士。
  - **Migros / Coop**：雙寡頭國民超市（橘色大 M 標誌的 Migros 絕不販賣菸酒）。
