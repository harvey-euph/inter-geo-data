# 墨西哥在地語言與街頭文字習慣
- priority: 20
- id: mexico-language
- targets: MX
- icon: 🇲🇽
- accent: #16a34a
- tags: Language, Geoguessr

- **【官方語言】**：西班牙語 (Español Mexicano)
- **【核心停讓與交通標誌】**：
  - **ALTO**：全美洲僅墨西哥與中美洲（瓜地馬拉、巴拿馬等）使用「**ALTO**」作為八角形停止標誌（南美洲一律使用「PARE」）。
  - *Ceda el paso*（讓路）、*Uno y uno*（墨西哥特有街口輪流禮讓制）、*Despacio*（慢行）。
  - **Topes / Reductor de velocidad**：墨西哥全國街道隨處可見的減速丘，路牌常寫 *Topes*。
  - *Desviación*（改道/施工改道）、*No estacionarse*（禁止停車，常縮寫為圓圈紅色斜槓「E」）。
- **【街頭超高頻商家招牌】**：
  - **Tienda de abarrotes**：墨西哥標誌性傳統雜貨店統稱。
  - **Tortillería**：玉米餅專賣烘烤舖，幾乎每個街區都有。
  - **Farmacia de Similares**：普及率極高的平價連鎖藥局，門口常有吉祥物「辛米博士」(Dr. Simi) 畫像或玩偶。
  - **OXXO**：紅黃相間招牌的國民連鎖超商，大街小巷與公路加油站必見。
  - *Vulcanizadora*（補胎修車行）、*Tacos / Taquería*（塔可玉米捲餅店）、*Carnicería*（肉舖）、*Panteón*（公墓/墓園）。
- **【門牌地址與社區劃分】**：
  - **Colonia (縮寫 Col.)**：墨西哥最關鍵的城鎮社區劃分，幾乎所有街名牌與門牌下方必標所屬社區（如 *Col. Juárez*, *Col. Centro*）。
  - *Alcaldía / Delegación*（區公所/行政區）、*Fraccionamiento (Fracc.)*（封閉式住宅建案區）。
- **【在地日常警示與俚語習慣】**：
  - *Cuidado con el perro*（小心惡犬）、*¡Aguas!*（小心！注意！）、*Se renta / Se vende*（招租/出售）。
  - 墨西哥特有日常口語：*Güey*（兄弟/老兄）、*Chido*（很酷/很讚）、*No manches*（少來了/誇張）。


# 瓜地馬拉在地語言與街頭文字習慣
- priority: 20
- id: guatemala-language
- targets: GT
- icon: 🇬🇹
- accent: #0ea5e9
- tags: Language, Geoguessr

- **【官方語言】**：西班牙語，並廣泛混合 22 種馬雅語族語言（K'iche', Kaqchikel 等）。
- **【核心停讓與交通標誌】**：
  - **ALTO**：八角停止標誌寫「ALTO」。
  - **Túmulo**：**瓜地馬拉全球獨有的減速丘稱呼**！公路與街口警示牌必定寫著「*TÚMULO*」或「*TÚMULOS A 100M*」（墨西哥稱 Topes，南美稱 Resalto/Lomo de burro）。
  - *Ceda el paso*、*Paso peatonal*（行人穿越道）。
- **【街頭商家招牌與生活關鍵字】**：
  - *Abarrotería* 或 *Tiendita*（社區微型雜貨舖）。
  - *Librería*（在瓜地馬拉街頭常兼營文具、影印與生活雜貨）。
  - *Comedor*（平民小吃餐廳）、*Tortillería*、*Pinchazos*（輪胎補胎攤）。
- **【城鎮地址特徵】**：
  - **Zona XX**：瓜地馬拉市（Guatemala City）及主要城鎮嚴格採用「分區制」（從 Zona 1 到 Zona 25），路牌與地址必定標明分區（如 *7a Avenida, Zona 9*）。
- **【馬雅語地名與在地詞彙】**：
  - 眾多城鎮地名以 *Chimaltenango*, *Quetzaltenango*, *Sololá* 等納瓦特/馬雅語命名，帶有大量「Ch-」「X-」「Tl-」。

- accent: #2563eb
- tags: Language, Geoguessr

- **【核心交通標誌】**：
  - **ALTO**：停止標誌使用「ALTO」。
  - *Ceda*（讓路縮寫標誌，常省略 el paso）、*Reductor de velocidad*（減速丘）。
- **【街頭招牌神級指標】**：
  - **Soda**：**哥斯大黎加特有國民平價餐館稱呼**！全境所有街角供應傳統便當 *Casado* 的小吃部一律招牌寫「*Soda*」（如 *Soda La Amistad*, *Soda El Parque*），非飲料汽水。
  - **Pulpería** 或 *Abastecedor*：傳統社區雜貨舖專屬稱謂。
  - *Veterinaria / Agroveterinaria*（農牧獸醫用品店，鄉村小鎮路邊極常見）。
- **【傳奇的「無門牌地標地址法」】**：
  - 哥斯大黎加除少數都會新區外，傳統門牌極少使用號碼，路標與店家地址常寫作相對地標描述（如 *De la Iglesia 200m Norte y 50m Este*：教堂往北200米再往東50米）。
- **【國民文化口頭禪】**：
  - **¡Pura Vida!**（純淨生活！）：哥斯大黎加的精神圖騰，見面打招呼、表達感謝、說再見皆可使用。自稱 *Tico*（男）/ *Tica*（女），稱呼朋友為 *Mae*。

# 阿根廷在地語言與街頭文字習慣

- **【官方語言】**：拉普拉塔西班牙語 (Español Rioplatense)，標誌性的 **Voseo**（以 *vos* 代替 *tú*，動詞變位 *tenés*, *sos*, *querés*）與將「ll / y」發作類似「sh / zh」音。
- **【核心停讓與交通標牌】**：
  - **PARE**：八角停止標誌寫「PARE」。
  - **Lomo de burro** 或 *Baden*：阿根廷對減速丘與路面凹陷排水槽的特有稱呼。
  - *Contramano*（逆向/單行道禁入）、*Cruce peatonal*、*Desvío*、*Velocidad máxima XX*。
- **【街頭神級辨識招牌】**：
  - **Kiosco**：阿根廷隨處可見的街頭小賣店，專售香菸、Alfajores 甜點、碳酸飲料與 SUBE 交通卡儲值。
  - **Rotisería**：熟食外帶餐館，招牌菜必備 *Empanadas*（烤餡餅）與 *Milanesas*（炸肉排）。
  - **Carnicería**：阿根廷人無肉不歡，各部位牛肉烤肉 (Asado, Bife de chorizo) 肉舖遍布街角。
  - **Gomería**：**阿根廷對補胎店的專有稱呼**（智利稱 Vulcanización，巴西稱 Borracharia）。
  - *Cochera*（收費停車場，西班牙稱 Aparcamiento）。
  - *Alquila / Vende*（房屋招租/售）。
- **【門牌地址習慣】**：
  - 城市街廓多為百位數遞增的大號碼門牌（如 *Avenida Corrientes 3450*），路牌柱通常標明街名與該街段號碼範圍（如 *200 - 300*）。
- **【在地俚語與日常呼喚】**：
  - *Che*（喂/朋友）、*Boludo*（哥們/傻瓜，極高頻朋友口頭禪）、*Pibe*（年輕人）、*Colectivo / Bondi*（公車）、*Subte*（布宜諾斯艾利斯地下鐵）。

  - **PARE**：停止標誌寫「PARE」。

  - **Droguería**：哥倫比亞對社區西藥局的最普遍稱呼。
  - **Panadería y Pastelería**：清晨營業的烘焙坊兼早餐咖啡店。

# 秘魯特色飲食：CHIFA 中餐館文化與歷史
- id: peru-chifa
- targets: PE
- icon: 🥟
- accent: #fbbf24
- tags: Culture, Travel

- **【街頭普及現象】** 在秘魯街道經常可見紅黃招牌或霓虹燈寫著「**CHIFA**」（僅利馬市區就有超過 6,000 家，各城鎮隨處可見）。
- **歷史淵源**：1849 年至 1874 年間，約 10 萬名廣東華工（苦力）被招募至秘魯沿海從事甘蔗、棉花莊園及鳥糞礦（Guano）苦役。契約結束脫離苦力後，華人定居利馬建立拉丁美洲最古老唐人街 (Barrio Chino)，並開設融合粵菜烹調與秘魯在地食材的平民餐館。
- **名稱由來與經典菜式**：「Chifa」源自廣東話「**食飯 / 饎飯**」(sik faan)，秘魯人直接以此作為中餐館與中秘融合菜的統稱。街頭常見名菜包括牛肉炒薯條 *Lomo Saltado*、廣東炒飯 *Arroz Chaufa*、炒麵 *Tallarín Saltado* 與餛飩湯 *Sopa Wantán*。


# 巴西大鐵鍋天線 (Parabólicas)：仰角與南北緯度的關係
- id: brazil-satellite-dishes
- targets: BR
- icon: 📡
- accent: #4ade80
- tags: Nature, Geoguessr

- **【家戶普及的衛星天線】** 在巴西的民宅前院、屋頂或圍牆邊，常見大型金屬網狀衛星天線（當地稱 *Antenas Parabólicas*），用以接收免費衛星電視訊號。
- **物理原理（赤道同步衛星）**：巴西接收電視訊號之通訊衛星定軌於**赤道正上方**（緯度 0°）。因為巴西全境皆在南半球，所有衛星小耳朵**皆面朝正北方 (North)** 對準赤道。
- **仰角 (Elevation) 與緯度變化**：天線仰角約為「90° - 當地緯度」：
  - **北部赤道區（亞馬遜、帕拉、羅賴馬，約 0°~5°S）**：天線幾乎**垂直指向頭頂正上方**（仰角 80°~90°，宛如朝天盛水的大碗盤）！
  - **東北部與中西部（巴伊亞、戈亞斯、巴西利亞，約 10°~15°S）**：天線向北微傾，仰角約 70°~75°。
  - **東南部核心區（聖保羅、里約，約 22°~23°S）**：天線朝北傾斜更明顯，仰角約 60°~65°。
  - **南部三邦（巴拉那、聖卡塔琳娜、南大河，約 25°~30°S+）**：天線明顯朝向北方地平線斜倒，仰角僅約 50°~55°！

# 阿根廷 vs 烏拉圭 vs 智利
- id: argentina-uruguay-chile
- targets: AR, UY, CL
- icon: 🇦🇷
- accent: #3b82f6
- tags: Geoguessr, Nature

- **阿根廷**：
 - 車牌：黑底白字（舊）或 Mercosur 白底黑字＋藍帶，常有省分縮寫
 - 關鍵路牌：「Ruta Nacional」、「Lomo de burro」，店面常見「Kiosco」、「Rotisería」、「Gomería」
 - 城市建築歐式感強，布宜諾斯艾利斯有明顯法式／義式巴洛克風格；潘帕斯平原開闊平坦
- **烏拉圭**：
 - 車牌：白底黑字，上方常有藍色「Uruguay」或 Mercosur
 - 店招必見「Almacén」，路旁常備「Agua Caliente」供馬黛茶取水；口頭禪愛講「Ta」
 - 鄉村公路兩側桉樹（尤加利樹）成排整齊，整體比阿根廷更乾淨靜謐
- **智利**：
 - 唯一滿街寫「Botillería」（酒專賣）與「Completos」（熱狗堡），出租寫「Se Arrienda」
 - 地形狹長，東側必定緊貼巨大的安地斯雪山山脈（山在東邊）；北部為極度乾燥的阿塔卡馬紅岩沙漠
